<h1 align="center">🐾 Sistema de Cadastro de Pets</h1>


<p align="center">
  Aplicação desenvolvida em <strong>Java puro</strong> para cadastro e gerenciamento de pets,
  com persistência de dados em arquivos.
</p>

---

## 📌 Sobre o Projeto

O **Sistema de Cadastro de Pets** foi desenvolvido com o objetivo de consolidar os conhecimentos adquiridos no curso <strong>Dev Dojo</strong> (até a aula 142).

O projeto foi construído a partir do desafio proposto pelo Dev Magro:

🔗 <a href="https://github.com/karilho/desafioCadastro" target="_blank">Repositório do Desafio</a>

A aplicação permite cadastrar, listar, atualizar e remover pets, utilizando armazenamento em arquivos locais para persistência dos dados.

Este projeto foi essencial para reforçar conceitos fundamentais da linguagem Java e boas práticas de programação.

---

## 🚀 Funcionalidades

- ✅ Cadastro de novos pets  
- ✅ Listagem de pets cadastrados  
- ✅ Atualização de informações  
- ✅ Remoção de registros  
- ✅ Persistência de dados em arquivos  

---

## 🛠️ Conceitos e Tecnologias Aplicadas

O projeto foi desenvolvido utilizando <strong>Java puro</strong>, aplicando os seguintes conceitos:

### 🔹 Orientação a Objetos (POO)
- Encapsulamento  
- Construtores  
- Métodos  
- Organização em classes  

### 🔹 Manipulação de Dados
- Arrays  
- Manipulação de arquivos  

### 🔹 Java IO
- File  
- FileReader / FileWriter  
- BufferedReader / BufferedWriter  

### 🔹 Tratamento de Exceções
- try/catch  
- throws  
- Validações personalizadas  

### 🔹 File Systems
- Criação e leitura de arquivos  
- Organização de diretórios  

### 🔹 Boas práticas de código
- Separação de responsabilidades  
- Organização de pacotes  
- Código limpo e legível
